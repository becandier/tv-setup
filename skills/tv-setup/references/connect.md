# Найти ТВ и подключить adb

## Найти в сети

Android TV объявляет себя по mDNS. Сначала ищи приставку сам, IP спрашивай у пользователя в последнюю очередь.

**Android TV Remote — есть почти на любом Android TV/Google TV, отладка не нужна:**

```sh
dns-sd -B _androidtvremote2._tcp          # macOS; Ctrl+C через пару секунд
dns-sd -L "<имя из списка>" _androidtvremote2._tcp   # имя хоста и порт
dns-sd -G v4 <host>.local                 # IPv4
avahi-browse -rt _androidtvremote2._tcp   # Linux, сразу с адресами
```

**Беспроводная отладка Android 11+ — видна, когда она включена:**

```sh
adb mdns services                         # если есть adb из platform-tools
dns-sd -B _adb-tls-connect._tcp
```

- Нашлось несколько ТВ — покажи список имён и спроси, какой настраивать.
- Не нашлось ничего — спроси IP. Он есть на ТВ: Настройки → Сеть → (сеть) → IP-адрес.

## Включить отладку на ТВ

Скажи пользователю по шагам (названия пунктов зависят от прошивки):

1. Настройки → Настройки устройства → Об устройстве → 7 раз нажать OK на «Сборка».
2. Назад → Для разработчиков → включить «Отладка по USB». Если есть «Отладка по сети» / «ADB по сети» — её тоже.
3. На Android 11+ без пункта «ADB по сети» включить «Беспроводная отладка».

## Подключиться

**Android 10 и старше, или есть «ADB по сети»:** классический порт 5555, `tools/tv.py` подключается сам.

```sh
TV_HOST=<ip> tools/venv/bin/python -I tools/tv.py --probe
```

При первом подключении на ТВ появится «Разрешить отладку по USB?». Пользователь отмечает «Всегда разрешать с этого
компьютера» и нажимает OK. Ключ `tools/tv.py` лежит в `tools/adbkey/` (в `.gitignore`, в репо не попадает).

**Android 11+ только с беспроводной отладкой:** порт меняется, нужно сопряжение кодом. `tools/tv.py` так не умеет,
поэтому через `adb` из Android SDK platform-tools:

```sh
adb pair <ip>:<порт сопряжения>      # код и порт: «Беспроводная отладка» → «Сопряжение по коду»
adb connect <ip>:<порт отладки>
adb tcpip 5555                        # открыть классический порт; держится до перезагрузки
TV_HOST=<ip> tools/venv/bin/python -I tools/tv.py --probe
```

После перезагрузки ТВ порт 5555 закрывается: повтори `adb connect` и `adb tcpip 5555`.

## Если соединение рвётся

Первое включение VPN, сон приставки и смена Wi-Fi рвут TCP-соединение adb. Подожди и повтори команду. `tools/tv.py`
переподключается на каждом вызове. Если ТВ спит, разбудить его может только пульт — попроси пользователя.
