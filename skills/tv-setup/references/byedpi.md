# ByeByeDPI для YouTube

[ByeByeDPI](https://github.com/romanvht/ByeByeDPI) (GPL-3.0, автор romanvht) — локальный VPN, который меняет
пакеты так, чтобы DPI провайдера не узнавал YouTube. Он ничего не проксирует наружу и ходит в сеть напрямую. В
этой настройке через него идёт только YouTube для ТВ: остальные приложения и adb его не видят.

## Что делает `tools/byedpi.sh`

1. **ABI:** берёт `getprop ro.product.cpu.abi` и APK этого ABI из последнего релиза (`BYEDPI_VERSION=v.1.8.2` —
   конкретный). Для неизвестного ABI — universal.
2. **Хеш:** сверяет SHA-256 файла с тем, что GitHub публикует в релизе.
3. **Подпись:** сверяет сертификат подписи (`apksigner verify --print-certs`) с авторским — SHA-256
   `77451075…7a8dfb`, CN=Roman Kostin. Чужая подпись или хеш — установки не будет.
4. **Установка:** ставит APK, если эта версия ещё не стоит.
5. **Стратегия:** задаёт её через экспортированный `ToggleActivity` приложения
   (`--es strategy … --ez only_update true`). Это его штатный способ, без нажатий.
6. **Файл настроек:** кладёт на ТВ `/sdcard/Download/tv-setup-byedpi.json` в формате экспорта самого ByeByeDPI:
   - режим VPN;
   - `dns_ip` пустой — системный DNS;
   - `applist_type: whitelist` и в списке только `com.google.android.youtube.tv`;
   - `autostart: true`;
   - та же стратегия.

7. **Согласие на VPN:** `appops set io.github.romanvht.byedpi ACTIVATE_VPN allow` — то же, что ставит кнопка OK в
   системном диалоге «Разрешить подключение к VPN?», поэтому диалог больше не появится.

Остальные настройки лежат в приватных настройках приложения, и снаружи их записывает только его собственный импорт.
**Его проходит агент сам**, кнопками через adb, — пользователя к пульту не отправляй.

## Импорт настроек — агент, по скриншотам

1. `am start -n io.github.romanvht.byedpi/.activities.SettingsActivity`
2. Меню в правом верхнем углу (три точки) → «Импорт настроек».
3. В файловом окне: `Download` → `tv-setup-byedpi.json`. Если ByeByeDPI просит доступ к файлам — разрешить.
4. В диалоге разделов оставить все отмеченными → OK. Приложение перезапустит экран.

Как нажимать: `input keyevent DPAD_UP/DOWN/LEFT/RIGHT/CENTER/BACK`, а где фокус пультом не доходит —
`input tap X Y` по координатам с полноразмерного скриншота (`exec-out screencap -p`, экран 1920×1080 или своё
разрешение). После **каждого** шага смотри скриншот: раскладка меню зависит от версии, вслепую не жми.
`uiautomator dump` на многих ТВ не работает (null root node) — полагайся на скриншоты.

### Запасной путь — те же настройки вручную

Если импорт недоступен (другая версия, нет файлового окна), выставь настройки в UI тем же способом:

1. Настройки → «Использовать командную строку» включить → поле аргументов: выделить, стереть
   (`input keyevent MOVE_END` и серия `DEL`), ввести стратегию `input text` (пробелы — как `%s`) → сохранить.
2. DNS — пустой / системный.
3. «Список приложений» → тип «Белый список» → поиск `youtube` (`input text youtube`) → отметить YouTube для ТВ
   (`com.google.android.youtube.tv`).
4. «Автозапуск» включить. BACK до главного экрана.

## Запуск

Главный экран ByeByeDPI → «Подключить» (или `am start -n io.github.romanvht.byedpi/.activities.ToggleActivity`).
Если всё же всплыл системный диалог VPN (appops не сработал на этой прошивке) — нажми OK сам кнопками/тапом: владелец
попросил настроить, это часть настройки.

**Проверка:**
- настройки ByeByeDPI: «Режим — VPN», «Список приложений — белый, 1», «Автозапуск» включён;
- `dumpsys connectivity | grep -o "Transports: [A-Z|]*"` — есть `VPN`;
- `appops get io.github.romanvht.byedpi ACTIVATE_VPN` — `allow`;
- YouTube: `am start -a android.intent.action.VIEW -d https://www.youtube.com/watch?v=aqz-KE-bpKQ
  com.google.android.youtube.tv`, через 20 с `dumpsys media_session` показывает `state=3`, а счётчик `tun0` в
  `/proc/net/dev` растёт. Скриншот видео будет чёрным (защищённый контент) — это нормально.

## Стратегия — под провайдера

```
-d1 -s1+s -s3+s -s6+s -s9+s -s12+s -s15+s -s20+s -s30+s -a1
```

Эта стратегия подобрана в октябре 2026 под одного провайдера в Дагестане. У другого провайдера или после смены его
DPI она может не сработать. Признак — YouTube не грузит видео при включённом VPN. Что делать:

- в ByeByeDPI есть «Тест стратегий» (Proxy test): он перебирает варианты и показывает рабочие для заданных
  доменов;
- найденную стратегию задать так: `BYEDPI_STRATEGY='<стратегия>' TV_HOST=<ip> tools/byedpi.sh --settings-only`.
  Скрипт её сохранит и обновит файл импорта.

## Откат

Отключить автозапуск и VPN можно в самом ByeByeDPI. Удалить приложение — `pm uninstall io.github.romanvht.byedpi`.
Это обычное стороннее приложение, его удаление ничего системного не трогает. Пилюля VPN лаунчера покажет его
состояние и выключит его одним нажатием.
